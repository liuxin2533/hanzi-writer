# PowerPoint 图形名称与 SVG 文件名一致

## 目标

VBS 将单独笔画 SVG 导入 PowerPoint 后，每个图形的名称必须与对应 SVG 文件名完全一致，包括 `.svg` 扩展名。

例如导出“三”时：

| SVG 文件名 | PowerPoint 图形名称 |
| --- | --- |
| `三_00.svg` | `三_00.svg` |
| `三_01.svg` | `三_01.svg` |
| `三_02.svg` | `三_02.svg` |
| `三_03.svg` | `三_03.svg` |

## 设计

在 VBS 调用 `Shapes.AddPicture` 创建图形后，直接将当前数组中的完整文件名赋给 `shape.Name`：

```vbscript
shape.Name = arrFiles(i)
```

该赋值放在动画判断之前。文件数组已经按文件名排序，且每个 SVG 文件名在导出目录中唯一，因此不会产生图形名称冲突。

## 保持不变

- SVG 文件命名规则保持不变。
- SVG 文件排序和导入顺序保持不变。
- `_00.svg` 底图不添加动画。
- `_01.svg` 第一笔单击触发。
- 后续笔画接续前一动画。
- 动画方向和持续时间保持不变。

## 验证

1. 检查生成的 VBS 中包含图形命名赋值。
2. 运行项目静态检查和生产构建。
3. 使用“三”的导出结果核对 SVG 文件名与 PowerPoint 图形名称一一相同。
